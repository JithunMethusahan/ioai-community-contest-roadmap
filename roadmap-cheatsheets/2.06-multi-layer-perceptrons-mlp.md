## ⚡ Core Idea
- An MLP composes affine layers and nonlinear activations; without nonlinearities, stacked linear layers collapse to one affine map.
- `Linear(in, out)` maps a batch `[B,in]` to `[B,out]`; final width equals class count or regression target count.
- Use raw logits with CrossEntropyLoss for multiclass classification.
- Universal approximation is an existence result, not a guarantee of easy optimization or generalization.

## 📐 Formula / Theory Box
For one hidden layer: h = φ(W₁x + b₁), z = W₂h + b₂. For X ∈ ℝᴮˣᵈ and W₁ ∈ ℝʰˣᵈ, H ∈ ℝᴮˣʰ. Backprop applies the chain rule through each layer.

## ⚠️ 3 Contest Traps
1. No activation between Linear layers means the whole stack remains linear.
2. Flattening images with the wrong input width causes shape errors.
3. CrossEntropyLoss expects integer class IDs (usually `torch.long`), not one-hot labels.

## 💻 Copy-Paste Contest Starter Code
```python
import torch
from torch import nn
X = torch.randn(64, 20)
y = torch.randint(0, 3, (64,))
model = nn.Sequential(nn.Linear(20, 64), nn.ReLU(),
                      nn.Linear(64, 32), nn.ReLU(),
                      nn.Linear(32, 3))
opt = torch.optim.AdamW(model.parameters(), lr=1e-3)
for _ in range(20):
    opt.zero_grad(set_to_none=True)
    loss = nn.functional.cross_entropy(model(X), y)
    loss.backward()
    opt.step()
print("loss:", loss.item())
```

## ✅ Quick Check
<details><summary>Q1 — Linear layers without nonlinearities produce?</summary>

A) Nonlinear map B) One affine map C) Decision tree

**Answer:** B. Composition of affine maps remains affine.
</details>

<details><summary>Q2 — For 4 classes, final logit width?</summary>

A) 1 B) 3 C) 4

**Answer:** C. Standard multiclass classification emits one score per class.
</details>

<details><summary>Q3 — Integer class IDs pair with?</summary>

A) CrossEntropyLoss B) MSE only C) Sigmoid + BCE

**Answer:** A. It is the standard multiclass objective.
</details>
