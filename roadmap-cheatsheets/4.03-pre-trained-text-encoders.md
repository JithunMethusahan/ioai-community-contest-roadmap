## ⚡ Core Idea
- A pretrained encoder maps token IDs to contextual hidden states; a task head maps a pooled representation to labels.
- Tokenizers define vocabulary, special tokens, padding, and truncation; pair each checkpoint with its own tokenizer.
- Use `AutoModelForSequenceClassification` for classification rather than guessing pooling behavior.
- Freeze the encoder for a fast baseline; fine-tune with a small learning rate and validation checkpointing.

## 📐 Formula / Theory Box
For tokens x₁…xₙ, the encoder produces H = [h₁,…,hₙ] ∈ ℝⁿˣᵈ. A classifier can use pooled h_cls: z = Wh_cls + b, with softmax(z) for class probabilities. The attention mask excludes padding positions.

## ⚠️ 3 Contest Traps
1. A tokenizer from a different model family creates incompatible token IDs.
2. Forgetting `attention_mask` allows padding tokens to affect attention/pooling.
3. Applying softmax before a model's built-in cross-entropy loss double-normalizes outputs.

## 💻 Copy-Paste Contest Starter Code
```python
import torch
from transformers import AutoTokenizer, AutoModelForSequenceClassification
name = "bert-large-uncased"
tok = AutoTokenizer.from_pretrained(name)
model = AutoModelForSequenceClassification.from_pretrained(name, num_labels=3)
batch = tok(["short example", "another text"], padding=True,
            truncation=True, max_length=128, return_tensors="pt")
labels = torch.tensor([0, 2])
model.train()
out = model(**batch, labels=labels)
out.loss.backward()
model.eval()
with torch.no_grad(): logits = model(**batch).logits
pred = logits.argmax(dim=-1)
```

<details><summary>Q1 — What pairs with a pretrained encoder?</summary>

A) Matching tokenizer B) Any tokenizer C) No tokenizer

**Answer:** A. Token IDs are model-specific vocabulary indices.
</details>

<details><summary>Q2 — Padding should be excluded using?</summary>

A) attention_mask B) dropout mask C) label smoothing

**Answer:** A. The mask distinguishes valid tokens from padding.
</details>

<details><summary>Q3 — A sequence classifier emits?</summary>

A) Class logits B) Image pixels C) Optimizer states

**Answer:** A. Its classification head maps a sequence representation to label scores.
</details>
