## ⚡ Core Idea
- Bagging trains on bootstrap samples and averages/votes; it mainly reduces variance.
- Random Forest adds feature randomness to bagged decision trees.
- Boosting adds learners sequentially to correct current residual/errors; learning rate and tree count control fit.
- Tree ensembles are strong tabular baselines and usually do not need feature scaling.

## ⚠️ 3 Contest Traps
1. Fit encoders/imputers before the split and validation information leaks into training.
2. Deep trees plus many boosting rounds can overfit; monitor held-out performance.
3. Soft voting requires aligned class-column order across estimators.

## 💻 Copy-Paste Contest Starter Code
```python
from sklearn.ensemble import RandomForestClassifier, HistGradientBoostingClassifier, VotingClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import f1_score
Xtr, Xv, ytr, yv = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)
rf = RandomForestClassifier(n_estimators=300, min_samples_leaf=2,
                            n_jobs=-1, random_state=42)
gb = HistGradientBoostingClassifier(max_iter=200, learning_rate=0.06,
                                    l2_regularization=1.0)
ens = VotingClassifier([("rf", rf), ("gb", gb)], voting="soft")
ens.fit(Xtr, ytr)
pred = ens.predict(Xv)
print("macro-F1:", f1_score(yv, pred, average="macro"))
```

## ✅ Quick Check
<details><summary>Q1 — Random Forest combines?</summary>

A) Sequential residual correction B) Bagging plus feature randomness C) Gradient descent

**Answer:** B. Trees use bootstrap samples and randomized feature subsets.
</details>

<details><summary>Q2 — Boosting learners are trained?</summary>

A) Independently B) Sequentially C) On test data

**Answer:** B. Each learner improves the current ensemble.
</details>

<details><summary>Q3 — What belongs inside each CV fold?</summary>
