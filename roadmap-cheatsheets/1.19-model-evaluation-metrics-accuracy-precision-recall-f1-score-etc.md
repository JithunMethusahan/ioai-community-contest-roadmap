## ⚡ Core Idea
- Accuracy is correct predictions / all predictions; it can hide minority-class failure.
- Precision asks “when predicted positive, how often correct?”; recall asks “how many actual positives found?”.
- F1 is the harmonic mean; macro averaging weights classes equally, weighted averaging weights by support.
- Match the evaluator's exact metric and averaging convention.

## 📐 Formula / Theory Box
For TP, FP, TN, FN: Precision = TP/(TP+FP); Recall = TP/(TP+FN); F1 = 2PR/(P+R) = 2TP/(2TP+FP+FN). Accuracy = (TP+TN)/(TP+FP+TN+FN). Define zero-division behavior when a denominator is 0.

## ⚠️ 3 Contest Traps
1. Using weighted-F1 when the evaluator expects macro-F1 overweights majority classes.
2. Passing probabilities without thresholding/argmax creates invalid class predictions.
3. Reversing the positive label silently changes the confusion counts.

## 💻 Copy-Paste Contest Starter Code
```python
from sklearn.metrics import accuracy_score, precision_recall_fscore_support
y_true = [0, 0, 0, 1, 1, 1]
y_pred = [0, 0, 1, 1, 0, 1]
acc = accuracy_score(y_true, y_pred)
p, r, f1, support = precision_recall_fscore_support(
    y_true, y_pred, average="macro", zero_division=0)
print({"accuracy": acc, "macro_precision": p,
       "macro_recall": r, "macro_f1": f1})
```

## ✅ Quick Check
<details><summary>Q1 — A false negative increases which count?</summary>

A) FP B) FN C) TN

**Answer:** B. An actual positive predicted negative is a false negative.
</details>

<details><summary>Q2 — Macro-F1 weights classes how?</summary>

A) Equally B) By support C) Majority class only

**Answer:** A. Compute each class F1, then average classes equally.
</details>

<details><summary>Q3 — False positives are costly; inspect closely?</summary>

A) Precision B) Recall only C) Accuracy only

**Answer:** A. Precision decreases as predicted positives contain more false positives.
</details>
