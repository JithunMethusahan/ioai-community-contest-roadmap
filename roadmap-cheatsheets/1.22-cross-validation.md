## ⚡ Core Idea
- K-fold CV trains on K−1 folds and validates on the remaining fold; each fold validates once.
- Use StratifiedKFold for classification; use group/time-aware splitters for dependent samples.
- Put preprocessing and estimator in a Pipeline so each transform is fitted only on its fold's training data.
- CV estimates generalization and supports tuning; keep a final holdout when the protocol permits.

## ⚠️ 3 Contest Traps
1. Scaling/imputing/selecting features before CV leaks validation-fold information.
2. Random K-fold on time series or repeated entities leaks future or group information.
3. Repeatedly selecting on the same CV estimate makes the reported best score optimistic.

## 💻 Copy-Paste Contest Starter Code
```python
from sklearn.pipeline import make_pipeline
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import StratifiedKFold, cross_val_score
pipe = make_pipeline(SimpleImputer(), StandardScaler(),
                     LogisticRegression(max_iter=1000))
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(pipe, X, y, cv=cv, scoring="f1_macro")
print("fold scores:", scores.round(3))
print("mean ± std:", scores.mean(), scores.std())
```

## ✅ Quick Check
<details><summary>Q1 — Where should StandardScaler.fit run?</summary>

A) Before CV on all data B) On each training fold C) On test fold

**Answer:** B. Fit only on fold training data and transform its validation fold.
</details>

<details><summary>Q2 — Best splitter for imbalanced classification?</summary>

A) StratifiedKFold B) Shuffle pixels C) TimeSeriesSplit always

**Answer:** A. It approximately preserves class proportions.
</details>

<details><summary>Q3 — Repeated patient records should usually be split by?</summary>

A) Random row B) Group identity C) Target value

**Answer:** B. Group splitting prevents the same entity appearing in train and validation.
</details>
