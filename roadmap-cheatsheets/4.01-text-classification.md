## ⚡ Core Idea
- Text classification maps each text to a fixed label; establish a TF-IDF + linear baseline before a neural model.
- Fit vectorizers on training text only; transform validation/test with the fitted vocabulary.
- Use stratified splits and the evaluator's exact metric; inspect class imbalance and label mapping.
- For Transformers, use the checkpoint's tokenizer and pass attention masks.

## ⚠️ 3 Contest Traps
1. Fitting TF-IDF on train + test leaks vocabulary/document-frequency information.
2. A different label encoder/class order at inference silently swaps predicted classes.
3. Missing attention masks or inconsistent padding/truncation changes transformer outputs.

## 💻 Copy-Paste Contest Starter Code

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline

## ✅ Quick Check
<details><summary>Q1 — Where should TF-IDF be fitted?</summary>

A) Training text only B) Train + test C) Test only

**Answer:** A. Fit vocabulary and document frequencies on training text only.
</details>

<details><summary>Q2 — For imbalanced classification, use?</summary>

A) Stratified split B) Sorted split C) Duplicate test labels

**Answer:** A. Stratification approximately preserves class proportions.
</details>

<details><summary>Q3 — Why keep a fixed label mapping?</summary>

A) Reproducible class IDs B) Faster tokenization C) Lower RAM

**Answer:** A. Inconsistent encodings silently swap class names.
</details>
