## ⚡ Core Idea
- A confusion matrix compares true labels (rows) with predictions (columns) under sklearn's default convention.
- ROC plots true-positive rate against false-positive rate across score thresholds; AUC summarizes ranking quality.
- ROC-AUC needs continuous scores/probabilities, not hard labels.
- For severe imbalance, inspect precision-recall behavior and choose an operating threshold deliberately.

## 📐 Formula / Theory Box
TPR = TP/(TP+FN); FPR = FP/(FP+TN). ROC-AUC = ∫₀¹ TPR(FPR) dFPR. AUC measures ranking quality, not calibration or performance at one fixed threshold.

## ⚠️ 3 Contest Traps
1. Passing hard predictions to ROC-AUC discards ranking information.
2. Assuming probability column 1 means class label 1 can fail when class order differs; inspect `classes_`.
3. ROC-AUC alone can hide poor precision on rare-positive tasks.

## 💻 Copy-Paste Contest Starter Code
```python
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix, roc_auc_score, roc_curve
model = LogisticRegression(max_iter=1000).fit(X_train, y_train)
pred = model.predict(X_val)
pos_col = list(model.classes_).index(1)
score = model.predict_proba(X_val)[:, pos_col]
cm = confusion_matrix(y_val, pred, labels=model.classes_)
auc = roc_auc_score(y_val, score)
fpr, tpr, thresholds = roc_curve(y_val, score, pos_label=1)
print("CM:", cm, "ROC-AUC:", auc)
```

## ✅ Quick Check
<details><summary>Q1 — ROC-AUC should receive?</summary>

A) Hard labels B) Continuous scores C) Confusion matrix only

**Answer:** B. Threshold ranking requires continuous scores/probabilities.
</details>

<details><summary>Q2 — FPR equals?</summary>

A) FP/(FP+TN) B) TP/(TP+FN) C) TP/(TP+FP)

**Answer:** A. It is the fraction of actual negatives incorrectly predicted positive.
</details>

<details><summary>Q3 — For extreme imbalance, also inspect?</summary>

A) PR curve B) Training accuracy C) Parameter count

**Answer:** A. Precision-recall behavior is often more informative for rare positives.
</details>
