## ⚡ Core Idea
- A pretrained encoder maps images to learned features; replace its classifier head with the contest's class count.
- Feature extraction freezes the backbone; fine-tuning unfreezes some/all layers using a smaller learning rate.
- Use the weights enum's preprocessing to match resize, crop, and normalization.
- Establish a frozen baseline before spending time/compute on fine-tuning.

## ⚠️ 3 Contest Traps
1. Forgetting to replace the classifier head with the dataset's number of classes.
2. Leaving backbone parameters trainable in a supposedly frozen feature-extractor baseline.
3. Using random training augmentation at validation/test instead of deterministic checkpoint preprocessing.

## 💻 Copy-Paste Contest Starter Code
```python
import torch
from torch import nn
from PIL import Image
from torchvision.models import resnet18, ResNet18_Weights
weights = ResNet18_Weights.DEFAULT
preprocess = weights.transforms()
model = resnet18(weights=weights)
for p in model.parameters(): p.requires_grad = False
model.fc = nn.Linear(model.fc.in_features, 5)
opt = torch.optim.AdamW(model.fc.parameters(), lr=1e-3)
image = Image.open("data/example.jpg").convert("RGB")
x = preprocess(image).unsqueeze(0)
y = torch.tensor([2])
model.train(); opt.zero_grad(set_to_none=True)
loss = nn.functional.cross_entropy(model(x), y)
loss.backward(); opt.step()
model.eval()
with torch.no_grad(): logits = model(x)
```

## ✅ Quick Check
<details><summary>Q1 — Feature extraction baseline usually?</summary>

A) Freezes backbone B) Freezes classifier head C) Randomizes pretrained weights

**Answer:** A. Train the new head while keeping pretrained features fixed.
</details>

<details><summary>Q2 — Which normalization should be used?</summary>

A) Arbitrary mean/std B) Checkpoint's expected preprocessing C) Never normalize

**Answer:** B. Pretrained weights expect a particular input distribution.
</details>

<details><summary>Q3 — Fine-tuning often uses?</summary>

A) Larger LR for all layers B) Smaller LR for pretrained layers C) No validation

**Answer:** B. Small updates preserve useful pretrained features.
</details>
