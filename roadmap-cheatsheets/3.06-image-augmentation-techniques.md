## ⚡ Core Idea
- Label-preserving transforms include flips, crops, mild color jitter, and affine transforms.
- Use stochastic augmentation only for training; validation/test preprocessing must be deterministic.
- Match transforms to task semantics: a flip may invalidate left/right labels, text, or orientation.
- Augmentation can reduce overfitting on small datasets but cannot repair wrong labels or distribution shift.

## ⚠️ 3 Contest Traps
1. Random transforms at validation/test make reported scores noisy.
2. Flipping orientation-sensitive images changes the correct target label.
3. Applying PIL-only transforms to an already-normalized tensor can cause type/range errors.

## 💻 Copy-Paste Contest Starter Code
```python
from torchvision import transforms
mean, std = [0.485,0.456,0.406], [0.229,0.224,0.225]
train_tfm = transforms.Compose([
    transforms.RandomResizedCrop(224, scale=(0.8,1.0)),
    transforms.RandomHorizontalFlip(0.5),
    transforms.ColorJitter(brightness=0.15, contrast=0.15),
    transforms.ToTensor(), transforms.Normalize(mean, std)])
eval_tfm = transforms.Compose([
    transforms.Resize(256), transforms.CenterCrop(224),
    transforms.ToTensor(), transforms.Normalize(mean, std)])
# Apply train_tfm to train data only.
# Apply eval_tfm to validation and test data.
```

## ✅ Quick Check
<details><summary>Q1 — Which split gets stochastic augmentation?</summary>

A) Training B) Validation C) Test

**Answer:** A. Validation/test should measure deterministic inputs.
</details>

<details><summary>Q2 — A horizontal flip is unsafe when?</summary>

A) Labels encode left/right orientation B) Images are RGB C) Batch size exceeds one

**Answer:** A. The transformation can change the label itself.
</details>

<details><summary>Q3 — Augmentation can help with?</summary>

A) Every mislabeled sample B) Overfitting from limited variation C) Data leakage

**Answer:** B. It increases useful variation but cannot fix bad labels or leakage.
</details>
