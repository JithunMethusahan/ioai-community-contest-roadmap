## ⚡ Core Idea
- Check `shape`, `dtype`, `device`, and `stride` before every model boundary.
- `permute` reorders axes; `unsqueeze` adds a size-1 axis; `flatten` merges dimensions.
- `view` requires compatible memory layout; `reshape` can copy when necessary.
- Broadcasting aligns dimensions from the right; each pair must match or one must be 1.

## ⚠️ 3 Contest Traps
1. PyTorch images are usually NCHW, not NHWC; wrong axis order silently breaks the model.
2. `view` after `permute` may fail on non-contiguous memory; use `reshape` or `.contiguous().view(...)`.
3. Shapes `(N,1)` and `(N,)` broadcast to `(N,N)`, not `(N,1)`.

## 💻 Copy-Paste Contest Starter Code
```python
import torch
x = torch.randn(8, 3, 32, 32)       # NCHW
print(x.shape, x.dtype, x.device)
tokens = x.flatten(2).transpose(1, 2)  # (8, 1024, 3)
tokens = tokens.reshape(8, 1024, 3)
mask = torch.ones(8, 1024, 1)
masked = tokens * mask
expanded = tokens.unsqueeze(1)
restored = expanded.squeeze(1)
assert restored.shape == (8, 1024, 3)
labels = torch.arange(8, dtype=torch.long)
```

## ✅ Quick Check
<details><summary>Q1 — After permute, which reshape works if a view is impossible?</summary>

A) view B) reshape C) squeeze

**Answer:** B. reshape may allocate a copy to satisfy the requested shape.
</details>

<details><summary>Q2 — Broadcasting (N,1) with (N,) produces?</summary>

A) (N,N) B) (N,1) C) error

**Answer:** A. The second shape aligns as (1,N).
</details>

<details><summary>Q3 — Standard PyTorch image batch layout?</summary>

A) NHWC B) NCHW C) HWC

**Answer:** B. Batch, channel, height, width.
</details>
