## ⚡ Core Idea
- A classifier maps image batches `[N,C,H,W]` to class logits `[N,K]`; CrossEntropyLoss uses integer class IDs.
- Create a reproducible train/validation split; fit preprocessing and class balancing on training data only.
- Match pretrained weights' input size, normalization, and channel order.
- At inference use `eval()` and `no_grad()`; keep the class-index mapping identical to training.

## ⚠️ 3 Contest Traps
1. Independently sorting train/test folders can produce inconsistent class-index mappings.
2. Random augmentation on validation/test makes metrics unstable and predictions non-reproducible.
3. Wrong normalization or RGB/BGR channel order can severely degrade pretrained models.

## 💻 Copy-Paste Contest Starter Code
```python
import torch
from torch import nn
from torchvision import datasets, transforms, models
from torch.utils.data import DataLoader
tfm = transforms.Compose([transforms.Resize((224,224)),
    transforms.ToTensor(), transforms.Normalize(
    [0.485,0.456,0.406], [0.229,0.224,0.225])])
ds = datasets.ImageFolder("data/train", transform=tfm)
loader = DataLoader(ds, batch_size=32, shuffle=True, num_workers=2)
model = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)
model.fc = nn.Linear(model.fc.in_features, len(ds.classes))
opt = torch.optim.AdamW(model.parameters(), lr=1e-4)
for images, labels in loader:
    opt.zero_grad(set_to_none=True)
    loss = nn.functional.cross_entropy(model(images), labels)
    loss.backward(); opt.step()
model.eval()
with torch.no_grad(): logits = model(next(iter(loader))[0])
```

## ✅ Quick Check
<details><summary>Q1 — Classification logits have shape?</summary>

A) [N,K] B) [K,N,H,W] C) [N] pixels

**Answer:** A. Each image receives one score per class.
</details>

<details><summary>Q2 — Random augmentation belongs on?</summary>

A) Training only B) Validation only C) Test only

**Answer:** A. Validation and test transforms should be deterministic.
</details>

<details><summary>Q3 — What must remain fixed at inference?</summary>

A) Class-index mapping B) Shuffled labels C) Random crop

**Answer:** A. Predicted indices must map to the same class names.
</details>
